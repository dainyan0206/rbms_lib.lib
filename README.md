# rbms — RoboMaster モーター制御ライブラリ(LQR対応版)

RoboMaster の M2006 P36(C610 電調)/ M3508 P19(C620 電調)を、mbed から CAN 経由で制御するクラス `rbms` です。
速度制御・位置制御・トルク(電流)制御を持ち、今回 **LQR(線形二次レギュレータ)による制御を追加**しました。

> ⚠️ **重要:LQR のパラメータは現段階では仮の値です**
> `set_lqr_params()` に渡している値(負荷慣性 J、各最大値など)は、動作確認のために**適当に入れたもの**で、実機に合わせた調整はこれからです。
> 実機での検証・チューニングを行ったうえで、値を更新していく予定です。使う場合は、必ず低いトルク制限・無負荷から試してください。

## 変更内容

### 追加したもの

| 項目 | 内容 |
|---|---|
| `set_lqr_params(id, J_load, u_max, theta_max, omega_max, zeta_max, eps_max)` | **モーター ID ごとに**、LQR の設計パラメータからゲインを自動計算して設定する |
| `disable_lqr(id)` | その ID の LQR(位置・速度とも)を無効にして、従来の PID に戻す |
| 速度モード | ゲインを LQR の式で決める(制御の形は従来どおりの PI) |
| 位置モード | 目標に近づいたら、位置・速度の状態フィードバック(位置 LQR)で指令値を直接出す |

`set_lqr_params()` を呼ばない ID は、動作が従来の PID のままです。LQR のゲインは ID ごとに保持されるので、負荷の違う関節ごとに別の値を設定できます。

### 修正したバグ

- `force_set_angle()`:`if(id>0 || ...)` を `if(id<0 || ...)` に修正(id = 0 以外がすべて弾かれていた)
- `_new_data_mask` がコンストラクタで初期化されていなかったので、`0` で初期化

## LQR とは

LQR(Linear Quadratic Regulator)は、現代制御の最適制御の手法の1つです。
システムの状態 $x$(ここでは位置と速度)をまとめてフィードバックして、入力 $u$ を次のように決めます。

$$u = -K x$$

ゲイン $K$ は、次の評価関数 $V$ を最小にするように計算で求めます。

$$V = \int_0^\infty \left( x^\top Q\, x + u^\top R\, u \right) dt$$

- $Q$:状態のずれ(位置ずれ・速度ずれ)をどれだけ嫌うか
- $R$:入力(トルク)の大きさをどれだけ嫌うか

**極(応答の速さ)を直接指定する極配置と違い、「何を重視するか」を $Q$、$R$ で決めると、最適な $K$ が決まる**のが特徴です。
$Q$ と $R$ は絶対値ではなく**比**で効きます(両方を同じ倍率で変えても $K$ は変わりません)。

一般には、$K$ はリカッチ方程式を解いて求めます。この制御対象(後述の二重積分器)では、リカッチ方程式が手で解けて、閉じた式になります。そのため、マイコン上でも `sqrt` の計算だけでゲインを求められます。

## このライブラリでのモデルと設計式

### モデル

電調(C610)に**電流(トルク)指令**を送るので、モーター出力軸は「指令に比例したトルクで加速する」二重積分器として扱います。

$$\ddot{\theta} = b\,u,\qquad b = \frac{K_t}{J}$$

| 記号 | 意味 | 値・単位 |
|---|---|---|
| $\theta$ | 出力軸の角度 | rad |
| $u$ | 電流指令値 | カウント(M2006/C610: ±10000 ↔ ±10 A、M3508/C620: ±16384 ↔ ±20 A) |
| $K_t$ | 指令値 1 カウントあたりの出力軸トルク | M2006: $1.8\times10^{-4}$ N·m/カウント(0.18 N·m/A × 10 A / 10000)<br>M3508: $3.66\times10^{-4}$ N·m/カウント(0.3 N·m/A × 20 A / 16384) |
| $J$ | 出力軸まわりの負荷慣性 | kg·m²(**仮置き**) |

摩擦・重力・電調の電流ループの遅れは無視しています。

### ゲインの式

$Q$、$R$ は、許容できる最大値の逆数の2乗(ブライソンの法則)で決めます。

$$q_1 = \frac{1}{x_{1,\max}^2},\quad q_2 = \frac{1}{x_{2,\max}^2},\quad r = \frac{1}{u_{\max}^2}$$

すると、ゲインは次の式になります。

$$k_1 = \frac{u_{\max}}{x_{1,\max}},\qquad k_2 = \sqrt{\left(\frac{u_{\max}}{x_{2,\max}}\right)^2 + 2\,k_1\,\frac{J}{K_t}}$$

閉ループの特性方程式は $s^2 + b k_2\, s + b k_1 = 0$ です。

### 位置制御と速度制御での使い分け

同じ式を、状態の取り方だけ変えて使います。

| | 位置制御 | 速度制御(積分つき) |
|---|---|---|
| $x_1$ | $\theta - \theta_{ref}$(角度ずれ) | $\int(\omega - \omega_{ref})\,dt$(速度誤差の積分) |
| $x_2$ | $\omega$(角速度) | $\omega - \omega_{ref}$(速度誤差) |
| $x_{1,\max}$ | `theta_max` [rad] | `zeta_max` [rad] |
| $x_{2,\max}$ | `omega_max` [rad/s] | `eps_max` [rad/s] |
| 制御則 | $u = k_1(\theta_{ref}-\theta) - k_2\,\omega$ | $u = k_1\int(\omega_{ref}-\omega)dt + k_2(\omega_{ref}-\omega)$ |

速度制御は、$k_2$ が比例ゲイン、$k_1$ が積分ゲインにあたる **PI 制御の形**です(既存の `pid_calculate` をそのまま使い、ゲインだけを LQR の式で決めています。ゲインは ID ごとに保持します)。

### コード内の単位

コードは角度が deg、速度が rpm(出力軸)なので、`set_lqr_params()` の中で次のように換算しています。

| 変数 | 単位 | 換算 |
|---|---|---|
| `_lqr_pos_k1` | カウント/deg | $k_1 \times \pi/180$ |
| `_lqr_pos_k2` | カウント/rpm | $k_2 \times 2\pi/60$ |
| `_lqr_spd_ki`(速度) | カウント/(rpm·s) | $k_1 \times 2\pi/60$ |
| `_lqr_spd_kp`(速度) | カウント/rpm | $k_2 \times 2\pi/60$ |

## 使い方

```cpp
rbms motor(can, false, 2);   // false: M2006, 2: モーター数

// 仮の値です。実機に合わせて調整してください(ID ごとに別の値を設定できます)
motor.set_lqr_params(0,        // id
                     0.01f,    // J_load    [kg·m²]  負荷慣性(仮置き)
                     5000.0f,  // u_max     [カウント] 使いたい最大指令値
                     0.5f,     // theta_max [rad]    許容する角度ずれ
                     10.0f,    // omega_max [rad/s]  許容する角速度
                     0.5f,     // zeta_max  [rad]    速度誤差の積分の許容値
                     2.0f);    // eps_max   [rad/s]  許容する速度誤差
motor.set_lqr_params(1, 0.02f, 4000.0f, 0.3f, 8.0f, 0.4f, 5.0f);   // id 1 は別の値
motor.spd_control();
```

この例だと、位置 LQR のゲインは約 192 カウント/deg と 129 カウント/rpm、速度 PI は `_ki` ≈ 1152、`_kp` ≈ 310 になります。

従来の PID に戻す場合は、次のとおりです。

```cpp
motor.disable_lqr(0);                      // ID 0 の位置・速度を従来の PID に戻す
motor.set_pid_gains(kp, ki, kd);           // 従来の速度 PID のゲインを変えたい場合(全 ID 共通)
```

## 動作の仕様

- **速度モード**:LQR が有効な ID は、その ID の LQR ゲイン(PI、kd = 0)で `pid_calculate` が動きます。無効な ID は従来の `_kp`、`_ki`、`_kd` です
- **位置モード**
  - `accel_limit` が設定されていて、誤差が `SETTLING_THRESHOLD`(25°)より大きいとき:従来の台形プロファイルで目標速度を作り、速度 PI(LQR のゲイン)で追従します
  - それより近いとき:位置 LQR が、`k1 × 角度ずれ − k2 × 速度` で指令値を直接出します(速度 PI は使いません)
  - `accel_limit` を設定していない場合は、位置 LQR が全域で働きます
- **トルク(電流)モード**:変更なし

出力は、これまでどおり `_motor_max` と `set_torque_limit()` の値で飽和します。

## パラメータの調整について

> **現段階の値は適当な仮値です。** 今後、実機で次の順に調整していく予定です。

1. 負荷慣性 `J_load`:CAD の値、または一定トルクをかけたときの角加速度から求める(J = Kt·i / α)
2. `u_max`:連続定格を超えない範囲で決める(M2006: 約 1 N·m ≈ 5500 カウント、M3508: 約 3 N·m ≈ 8192 カウント)
3. `theta_max`、`omega_max`、`zeta_max`、`eps_max`:応答を見ながら調整する

調整の目安は次のとおりです。

| 症状 | 動かすところ |
|---|---|
| 位置の戻りが遅い | `theta_max` を小さくする(入力は増える) |
| 振動する、行き過ぎる | `omega_max` を小さくする(減衰が増える) |
| トルクが足りない、電調が熱い | `u_max` を下げる |
| 速度の定常偏差が消えるのが遅い | `zeta_max` を小さくする |
| 速度の追従が荒い | `eps_max` を大きくする(ゲインが穏やかになる) |

`J_load` が実際の値とずれても、閉ループは直ちには不安定になりません。ただし、実際より大きく見積もるとゲインが高くなり、飽和や離散化の影響が出やすくなります。小さめの値から始めて上げていくのが安全です。

## 既知の制限・注意点

- モデルは**摩擦と重力を無視した二重積分器**です。垂直方向の関節など、重力がかかる場合は定常偏差が残ります(積分項の追加が必要)
- $K_t$ は、データシートの値(M2006: 0.18 N·m/A、M3508: 0.3 N·m/A)を**出力軸側の値**として使っています(データシートに明記はありませんが、定格トルクと定格電流の関係と整合します)
- 位置 LQR には `speed_limit` の制限をかけていません
- 位置 LQR は、目標付近での摩擦(静止摩擦)で小さな偏差が残る可能性があります(旧 `DEAD_BAND` の処理は、LQR 有効時は使われません)
- 位置制御の遠距離ゾーン→近距離ゾーンの切り替え時に、指令値が急に変わる可能性があります
